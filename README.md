# Biblioteca

Projeto que estou desenvolvendo durante meus estudos de Java Backend.

## Tecnologias

- Java 25
- Spring Boot
- JDBC
- PostgreSQL
- Jackson
- Lombok
- Maven

## O que o projeto faz

Atualmente estou praticando consumo de API utilizando a OMDb API
e conversão de JSON para objetos Java usando Jackson.

Também estou trabalhando na integração com PostgreSQL utilizando JDBC.
